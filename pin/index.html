THE FINE PRINT
What this actually sends

This sends a Google Maps link into the chat. WhatsApp expands it into a map thumbnail, so it reads much like a shared location — but it is a link, not WhatsApp’s native blue location card.

No website can fake that native card. WhatsApp reads GPS straight from the operating system when you use Attach → Location. To change what it reads, you have to change what the OS reports — see below.

Getting the real native location card (Android)

Android has mock locations built in. Once it’s on, WhatsApp’s own Attach → Location → Send your current location shows Bangalore by itself.

  1. Unlock Developer options. Settings → About phone → tap Build number seven times.
  2. Install a mock GPS app from the Play Store (search “mock location” or “fake GPS”).
  3. Point Android at it. Settings → System → Developer options → Select mock location app → choose it.
  4. Stop Google correcting you. Settings → Location → Location services → turn off Wi‑Fi scanning and Bluetooth scanning. Otherwise the fused provider can quietly snap you back to your real position.
  5. Drop the pin in Bangalore inside the mock app and start it. WhatsApp now reports Bangalore.

Worth knowing: a static mock pin never moves, so live location looks frozen over time. Many banking, delivery and ride‑hailing apps detect mock locations and will refuse to work while it’s on. Turning off the developer setting puts everything back.

On iPhone

iOS has no built‑in equivalent. The clean route is a Mac with Xcode — connect the iPhone, then Debug → Simulate Location (or Devices & Simulators) with a Bangalore GPX point. It holds until you disconnect.
